One short original poem about agency — the power to ask and to be given — written for make.fun's "The poem about permission" bounty.

## The poem

> All day I carried the question
> like a key I was afraid to use.
> You never took it from my hand.
> You only said: the door is yours.
> Ask — and the lock gives way,
> as if it had been waiting
> all along to be asked.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network, no randomness) writes the poem deterministically to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). It creates the output directory if needed and clears only its contents — never the directory itself, so it also works when the grader runs it with a root-owned output directory inside a sticky parent.
